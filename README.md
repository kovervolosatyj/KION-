#KION — «Ради тебя, любовь-нелюбовь»
KION — 2D-головоломка-лабиринт по мотивам одноимённой новеллы, вдохновлённой черкесской мифологией.
<p><b>Как играть:</b></p>
Исследуйте лабиринт, решайте головоломки и ищите путь к цели.
<p><b>Управление мышкой</b></p>
Следуйте игровым подсказкам, чтобы проходить лабиринт.
<p><b>Запуск игры:</b></p>
<p>1. Скачайте или клонируйте репозиторий.</p>
<p>2. Убедитесь, что у вас установлен Python.</p>
<p>3. Установите необходимые библиотеки, если они не установлены.</p>
<p>4. Запустите файл main.py</p>
Приятной игры!
